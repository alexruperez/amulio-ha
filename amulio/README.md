# aMulio for Home Assistant OS

> **Experimental.** This app builds the aMulio node locally on the Home Assistant machine. The first published release will provide prebuilt multi-architecture images.

## What it runs

One app container supervises `amuled`, `amuleapi` and the [aMulio core](https://github.com/alexruperez/amulio). Queue state, configuration, temporary files and completed downloads stay in the app's private `/data` directory on the HAOS host.

- aMule EC and amuleapi bind only to `127.0.0.1` inside the container.
- The app generates private install, signing and aMule control secrets on first boot under `/data/secrets`.
- The Stremio URL is generated by aMulio; it is not an HA Ingress URL.
- Peer ports are off by default. Enable host mappings deliberately if you want inbound eD2K/Kad connectivity.

## Configuration

| Option | Meaning |
| --- | --- |
| `public_url` | Reachable LAN or HTTPS origin used in Stremio manifests and playback links. This must not be the Home Assistant Ingress URL. |
| `peer_tcp_port` | eD2K TCP port used by `amuled`. |
| `peer_udp_port` | Kad UDP port used by `amuled`. |
| `preferred_languages` | Comma-separated metadata search language preference. |
| `allow_season_packs` | Whether series season packs may be candidates. |

The default `http://homeassistant.local:8000` is a placeholder. Before using Stremio, replace it with the exact host and port that the Stremio client can reach, or with your user-managed HTTPS proxy/tunnel origin.

## Backup scope

Home Assistant backups retain the app's configuration and aMulio database. Incomplete downloads (`/data/temp`) and the aMule log are excluded. Completed media lives under `/data/incoming`; decide separately whether that volume belongs in your backup policy.

## Security model

No Docker socket, Supervisor API, Home Assistant API, host networking, host PID namespace, or extra Linux capabilities are requested. Do not use a broad Cloudflare API token: remote HTTPS remains a user-managed network decision.
